# SmartFit

Sitio web de un gimnasio hecho con **HTML5, CSS y JavaScript** (sin frameworks).

## Ver el sitio

Publicado con GitHub Pages: `https://USUARIO.github.io/smartfit/`

## Páginas

- `index.html` – Inicio
- `registro.html` / `datos.html` – Registro del usuario
- `gimnasios.html` / `ubicate.html` – Sedes
- `rutina.html`, `ejercicios.html`, `musculos.html`, `espacios.html` – Rutinas y ejercicios

## Estructura

```
smartfit/
├── index.html y demás páginas .html
├── css/styles.css
├── js/app.js   (lógica)
├── js/data.js  (datos de sedes y ejercicios)
└── img/        (imágenes de las sedes)
```
